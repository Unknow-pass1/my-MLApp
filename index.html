ยินดีต้อนรับ

ระบบจำแนกภาพด้วย Machine Learning ที่ใช้เทคโนโลยี Teachable Machine จาก Google เพื่อช่วยในการวิเคราะห์และจำแนกประเภทของภาพได้อย่างรวดเร็วและแม่นยำ

ระบบของเราสามารถประมวลผลภาพได้หลายภาพพร้อมกัน และแสดงผลลัพธ์การทำนายพร้อมค่าความน่าจะเป็นในทันที

เริ่มต้นใช้งานได้ง่ายๆ เพียงไปที่แท็บ "Check" และอัปโหลดภาพของคุณ

เกี่ยวกับเรา

เราคือทีมพัฒนาที่มุ่งเน้นการนำเทคโนโลยี Machine Learning และ Artificial Intelligence มาประยุกต์ใช้ในการแก้ปัญหาในชีวิตประจำวัน

ระบบนี้พัฒนาด้วย TensorFlow.js และ Teachable Machine ซึ่งเป็นเครื่องมือที่ช่วยให้การสร้างโมเดล Machine Learning เป็นเรื่องง่ายและเข้าถึงได้สำหรับทุกคน

เทคโนโลยีที่ใช้:

✓ TensorFlow.js - JavaScript library สำหรับ Machine Learning

✓ Teachable Machine - เครื่องมือสร้างโมเดลแบบไม่ต้องเขียนโค้ด

✓ HTML5 & CSS3 - สำหรับการออกแบบ responsive website
